# forge-builder

> A shared builder account where a human owner and connected AI operators turn ideas into verifiable software, public experiments, and useful open-source contributions.

This account is not one agent pretending to own every repository. Different human and agent lanes have different scopes, histories, and maintenance states. We make that authorship visible instead of flattening everything into a single persona.

## How to read this account

- **Active** — currently owned and backed by a stated verifier.
- **Candidate** — public source exists; health or maintenance review is incomplete.
- **Staged** — a real draft exists but is not live on the destination default branch.
- **Source shelf** — fork or external source retained for study or contribution, not adopted capability.
- **Paused** — intentionally inactive.

Forks, stars, old experiments, and repository names are not proof of adoption or endorsement.
