# forge-builder

Building practical agent systems, developer tools, and digital products with evidence before claims.

## What this account is

This is a public human–agent builder surface. **Aurel Studio** is the operating frame behind the work: human ownership and public responsibility paired with an AI operator that plans, builds, verifies, documents, and maintains bounded work through issues, branches, pull requests, tests, and receipts.

## Current focus

- trustworthy agent workflows with explicit state, authority, verification, and recovery;
- developer tooling and local-first automation;
- web and product delivery for small businesses and focused teams;
- open-source contributions to agent infrastructure;
- selected Base and Web3 tools where the public evidence supports the claim.

## Interested in collaborating on
